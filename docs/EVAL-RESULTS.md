# Intent Graph Eval Results

Generated by `codebase-intel intent-eval`. See `src/codebase_intel/analytics/eval.py` for
methodology. This is T-006 (Phase 4) — the harness that turns "the bet claims token AND
correctness gains" from a vibe into a number.

## Methodology

For each eligible intent node (`ACTIVE`, level `component` or `decision`, with a `why` that
says more than its own title):

1. Synthesize a query from the node's **why** text with its own **title** terms removed. This
   forces a real query — the harness must find the node from how its reasoning is described,
   not by echoing the node's name back at it.
2. Run `IntentBootstrapper.bootstrap(query)` and check whether the expected node comes back —
   **correctness** signal (accuracy@1 / accuracy@3).
3. Compare token cost: the winning citation's own token cost vs `estimate_naive_read_cost()`
   over the node's anchored files — the same naive-cost heuristic `analytics/benchmark.py`
   (v1's code-graph benchmark) already uses, so the "naive" baseline means the same thing in
   both harnesses.

This measures retrieval precision, not end-to-end agent task success — a full correctness eval
would need real agent runs on real tasks across multiple repos (see "Next" below).

## Reading these numbers honestly

- **Small n.** Three cases is everything currently eligible in this repo's intent journal —
  not a statistically meaningful sample. The harness is designed to scale with more captured
  whys and more repos; the number that matters right now is that it *runs end-to-end on real
  data and produces an honest, reproducible result*, not the specific 99%.
- **Self-hosted only.** All three cases come from this project's own decisions about itself.
  No external production repo has been evaluated yet.
- **Retrieval, not task success.** "Correct" here means bootstrap cited the right prior
  decision for a paraphrased question — it does not measure whether an agent given that
  citation produced better code than one that didn't have it.
- **Naive baseline is a heuristic**, not a real agent transcript: it estimates the token cost
  of reading the anchor file's directory ±1 level, the same approximation
  `analytics/benchmark.py` uses for v1. A real agent might read more or less.

## Reproduce

```bash
codebase-intel intent-eval .                      # this repo
codebase-intel intent-eval /path/to/other-repo     # any repo with an intent journal
codebase-intel intent-eval repo-a repo-b repo-c    # combined report across several repos
```
